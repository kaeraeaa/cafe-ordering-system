# Café Aura — Frontend

Готовий React Frontend для навчального проєкту «Вебсистема онлайн-замовлень у кав’ярні».

## Технології

- React
- JavaScript
- Vite
- React Router
- CSS
- Fetch API

## Підключення до Backend

За замовчуванням Frontend звертається до:

`http://localhost:5000/api`

За потреби створи `.env`:

```env
VITE_API_URL=http://localhost:5000/api
```

## Запуск

```bash
npm install
npm run dev
```

Після запуску відкрий:

`http://localhost:5173`

## Потрібний Backend

Запусти попередньо створений Node.js Backend на порту `5000`.

Послідовність:

1. Запустити PostgreSQL.
2. Запустити Backend.
3. Запустити цей Frontend.

## Основні сторінки

- `/` — головна
- `/menu` — меню
- `/cart` — кошик
- `/login` — вхід
- `/register` — реєстрація
- `/profile` — особистий кабінет
- `/orders` — історія замовлень
- `/admin` — адміністративна панель

## Що реалізовано

- адаптивний дизайн;
- меню з категоріями та пошуком;
- кошик з кількістю товарів;
- реєстрація та авторизація;
- JWT через Backend;
- оформлення замовлення;
- історія замовлень;
- особистий кабінет;
- адмін-панель;
- додавання/редагування/видалення товарів;
- зміна статусів замовлень;
- стани завантаження та помилок.
